# Planilhas do projeto anuario

Envie aqui (Add file → Upload files) as planilhas preparadas pela equipe: .xlsx, .csv ou .json.
Use sempre o mesmo nome de arquivo para a mesma base. A fonte correspondente é configurada em `fontes/anuario.yml`.

**Não envie planilhas com dados pessoais** (nomes, CPFs, salários): este repositório é público.
